Helm for Windows — Setup Instructions
======================================

1. Extract HelmWindows.zip anywhere on your computer
2. Double-click Helm.exe to launch
3. Helm will open in your browser at http://localhost:5001
4. A ship's wheel icon will appear in your system tray (bottom right)

Requirements:
- Windows 10 or 11
- Your TV and PC must be on the same WiFi network

To run at startup:
- Press Win+R, type "shell:startup", press Enter
- Create a shortcut to Helm.exe in that folder
